### 🚀 About Me

I focus on **Adaptive Learning Systems** and **AI-driven Education Technology**. My goal is to bridge the gap between intelligent tutoring systems and modern LLM capabilities.

- 🔭 I'm currently working on **[AstraMentor](https://github.com/maxwell-orange/AstraMentor-v1)**, an intelligent tutoring system powered by multi-agent orchestration.
- 🤖 I built **[Huiyin Bar](https://github.com/maxwell-orange/huiyin_bar)**, an AI-driven multi-agent backend system for music bar recommendations.
- 🎨 I'm envisioning **[LogicDraw](https://github.com/maxwell-orange/LogicDraw)**, a visual coding platform to resolve ambiguity in prompt-based programming.
- 🌱 I'm currently learning advanced **Agentic Workflows** and **Graph Neural Networks**.
- 💬 Ask me about **Python, React, FastAPI, and LLM Integration**.
